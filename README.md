# Lumi en el bosque de colores

Versión inicial recibida como **Lumi en el bosque de colores 1.2**. El proyecto de Godot se encuentra en la raíz del repositorio.

## Abrir el proyecto

1. Instala Git LFS y ejecuta `git lfs install` antes de clonar el repositorio.
2. Clona el repositorio. Si ya lo clonaste, ejecuta `git lfs pull` para descargar los archivos grandes.
3. Importa `project.godot` en Godot 4.5, la versión indicada por el proyecto.
4. Espera a que termine la importación de recursos y ejecuta el juego con F6 (escena actual) o F5 (proyecto).

## Contenido original

Esta carga conserva los scripts, escenas, imágenes, sonidos, videos y demás archivos entregados, incluidos los archivos temporales y las copias comprimidas. No se han realizado cambios en la lógica del juego.

Los archivos ZIP, PCK y EXE se almacenan mediante Git LFS. La caché `.godot/` y la carpeta generada `android/` quedan excluidas según el `.gitignore` recibido.
